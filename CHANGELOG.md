# Changelog

## 0.3.9 - September 25, 2026

- Gave Boojie Friend Dots a fresh new look with a crisp black-and-pink **BFD** icon throughout the addon.
- Rebuilt the settings window to match the Boojie family: black background, pink border and accents, cleaner controls, and the current version displayed right beside the title.
- Added the `/bfd` shortcut where it is easy to find at the top of the window.
- Replaced the old home-grown minimap button with proper LibDataBroker and LibDBIcon support, so WindTools can tuck it neatly into its minimap button bar.
- Retired the old icon artwork and swept away the minimap-button code it no longer needed.
- Existing preferences—including the minimap-button toggle and saved window position—will carry forward automatically.

## 0.3.8 - September 24, 2026

- Added login and logout notifications for Battle.net friends who are online outside World of Warcraft. Their BattleTag is shown instead of a character name.
- Friends playing World of Warcraft still appear by character name and class color.

## 0.3.7 - September 24, 2026

- Fixed an issue that could show “logged out” without saying which friend logged out. The addon now uses the character name when available and falls back to the friend’s Battle.net name when needed.
- Friend names in login and logout messages now use their class colors.
