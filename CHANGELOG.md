# Changelog

## 0.3.8 - September 24, 2026

- Added login and logout notifications for Battle.net friends who are online outside World of Warcraft. Their BattleTag is shown instead of a character name.
- Friends playing World of Warcraft still appear by character name and class color.

## 0.3.7 - September 24, 2026

- Fixed an issue that could show “logged out” without saying which friend logged out. The addon now uses the character name when available and falls back to the friend’s Battle.net name when needed.
- Friend names in login and logout messages now use their class colors.
